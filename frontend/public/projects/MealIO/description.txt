Project Title:
MealIO – Automated Robot for Domestic Food Preparation

Project Category:
Embedded Systems Design Project

Project Description:
MealIO is a smart domestic cooking robot designed to automate ingredient dispensing, stirring, liquid control, and key meal preparation tasks. It integrates ESP32-S3 and Arduino control, sensors, a touchscreen interface, and a Flutter mobile app, supported by Proteus simulation and SolidWorks 3D design.
