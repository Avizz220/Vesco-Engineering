Project Title: RuGrow – IoT-Based Smart Plant Growing System (Version 1.0.0)

Project Category: Embedded Systems, IoT & Machine Learning

Project Description:
RuGrow is an innovative IoT-based automated plant-growing system designed as an alternative to traditional greenhouses. It integrates ESP32-S3, Arduino-based linear actuator control, environmental sensors, and Azure AI Custom Vision for plant recognition, fruit detection, and disease identification. The system automatically manages watering, temperature, humidity, and artificial lighting based on real-time sensor data, with live monitoring through the RuGrow App.
